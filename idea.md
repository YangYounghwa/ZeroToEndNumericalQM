# Numerical quantum mechanics: original idea

Learn from simple problems to advanced methods:

1. One-particle Schrödinger equation: finite differences, quadrature, diagonalization.
2. Time evolution: Crank-Nicolson, split operators, Krylov methods.
3. Few-body systems: sparse matrices and Lanczos.
4. Many-body systems: exact diagonalization.
5. Large many-body systems: MPS, DMRG, and tensor networks.
6. Quantum Monte Carlo: VMC, DMC, and AFQMC.
7. Modern methods: neural quantum states, differentiable physics, and GPU tensor networks.

Use the `ZeroToEndNumericalQM` repository. Develop one chapter at a time.
Each chapter needs physics notes, numerical methods, and Python coding hints.
Build NumPy and PyTorch versions.

See the [current roadmap](ROADMAP.md) for the learning order and scope.
